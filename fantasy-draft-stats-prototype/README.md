# Fantasy Draft Statistics Prototype

Saved checkpoint from September 4, 2026.

## Current prototype
- Browser-based fantasy draft analytics dashboard
- ESPN league 71826188, 2026 season
- 10-team, 16-round snake draft
- 160 draft picks
- Dashboard cards for total/manual/auto picks and positional counts
- Biggest reaches vs ESPN ADP
- Biggest fallers vs ESPN ADP
- Complete draft board
- Player headshots and NFL team logos via ESPN image URLs
- ESPN ADP comparison and auto-draft flags

## Next planned steps
As more leagues are added, expand to:
- Observed ADP across all test leagues
- Median, earliest, latest pick
- Standard deviation / volatility
- Reach and fall percentages
- Round and pick distributions
- Player-vs-player draft rates
- Availability probability at each future pick
- “Will this player make it back to me?” probability
- Filters for manual vs auto-drafted picks
- League-setting segmentation (team count, scoring, format)

## Privacy
Raw ESPN league exports and account data are intentionally not stored in this public repository. This folder contains only the browser-friendly prototype/checkpoint.
